Set up (once)

  1. Make the Instagram account professional. In the Instagram app: Settings → Account type and tools → Switch to professional account → Business. It's free.
  2. Create a Meta app. Go to developers.facebook.com/apps → Create app → use case Manage messaging & content on Instagram → name it “Island Stay publisher”.
  3. Set up Instagram login. In the app: Instagram → API setup with Instagram login.
    • Under “Generate access tokens”, add the Island Stay Instagram account (this makes it a tester, so no app review is needed).
    • Under “Set up Instagram business login” → Business login settings, paste this as the OAuth redirect URI:
      {{ callback_url }}
    • Copy the Instagram app ID and Instagram app secret shown at the top of that page.
  4. Add the keys to Vercel. Vercel → islandstay → Settings → Environment Variables, for Production:
    NameValueStatus
    INSTAGRAM_APP_IDInstagram app ID{% if configured %}Set{% else %}Missing{% endif %}
    INSTAGRAM_APP_SECRETInstagram app secret{% if configured %}Set{% else %}Missing{% endif %}
    CRON_SECRETAny long random text (keeps the timer link private){% if has_cron_secret %}Set{% else %}Missing{% endif %}
    Then Deployments → ⋯ → Redeploy, come back here and press Connect Instagram.
  5. Start the timer. Instagram can't schedule API posts itself, so this site checks for due posts. Sign up free at cron-job.org → Create cronjob:
    • URL:
      {{ cron_url }}?key={% if cron_secret %}{{ cron_secret }}{% else %}YOUR_CRON_SECRET{% endif %}
      {% if not cron_secret %}Replace YOUR_CRON_SECRET with the value you set in Vercel.{% endif %}
    • Schedule: every 10 minutes. Leave the rest as it is.

Using it

  1. Open a post's design, check it, and press Schedule on Instagram. The design is saved as a JPG and the post is queued for its date.
  2. Carousels: add 1 to 9 more slides on the design page first. Reels: upload the MP4 (vertical, 3 to 90 seconds); the design becomes the cover.
  3. At the post's time it goes out, the status changes to Posted and the Instagram link is saved.
  4. Changed the post after queuing? Press Update on Instagram to save the new image and caption.

Good to know

  • Stories are published without stickers: Instagram's API can't add polls, questions or link stickers. For those Stories, add the sticker in the app instead (the sticker note says which).
  • Instagram caps how many posts the API can publish each day, far above the one or two a day this plan uses.
  • If a post fails (for example a video Instagram can't read), it's tried 3 times, then shown here in red with the reason.
