Set up (once)

  1. Make the Instagram account professional. In the Instagram app: Settings → Account type and tools → Switch to professional account → Business. Skip connecting a Facebook Page.
  2. Meta app. At developers.facebook.com/apps, create an app with the use case Manage messaging & content on Instagram and link it to a business portfolio (free; no Page needed).
  3. Make your Instagram a tester. In the app: App roles → Roles → Add people → Instagram Tester → type the Island Stay username. Then accept the invite: on instagram.com go to Settings → Apps and websites → Tester invites → Accept.
  4. Generate the access key. In the app: Use cases → Customize → API setup. With Unified login, first press Create new configuration in step 1 (General, system-user token, Instagram account: Island Stay) and select it. Then 2. Generate access tokens → Add account → Generate token. Copy the token and paste it in the box at the top of this page, with the Instagram account ID (the number under the account name, 17841…). It's checked straight away.
  5. Start the timer. Instagram can't schedule API posts itself, so this site checks for due posts. Sign up free at cron-job.org → Create cronjob:
    • URL:
      {{ cron_url }}?key={% if cron_secret %}{{ cron_secret }}{% else %}YOUR_CRON_SECRET{% endif %}
      {% if not cron_secret %}Replace YOUR_CRON_SECRET with the CRON_SECRET value from Vercel.{% endif %}
    • Schedule: every 10 minutes. Leave the rest as it is.

Using it

  1. Open a post's design, check it, and press Schedule on Instagram. The design is saved as a JPG and the post is queued for its date.
  2. Carousels: add 1 to 9 more slides on the design page first. Reels: upload the MP4 (vertical, 3 to 90 seconds); the design becomes the cover.
  3. At the post's time it goes out, the status changes to Posted and the Instagram link is saved.
  4. Changed the post after queuing? Press Update on Instagram to save the new image and caption.

Good to know

  • Stories are published without stickers: Instagram's API can't add polls, questions or link stickers. For those Stories, add the sticker in the app instead (the sticker note says which).
  • Instagram caps how many posts the API can publish each day, far above the one or two a day this plan uses.
  • If a post fails (for example a video Instagram can't read), it's tried 3 times, then shown here in red with the reason.
