How to set it up (about 5 minutes)

Option A: Gmail (simplest)

  1. On the Google account that should send the emails, turn on 2-Step Verification (myaccount.google.com, Security).
  2. Open myaccount.google.com/apppasswords, create an app password named “Island Stay” and copy the 16 letters.
  3. In Vercel open your project, Settings, Environment Variables, and add:
    EMAIL_HOSTsmtp.gmail.com
    EMAIL_PORT587
    EMAIL_HOST_USERthe Gmail address
    EMAIL_HOST_PASSWORDthe 16-letter app password
    ADMIN_NOTIFY_EMAILSwhere new-listing alerts should go (optional)
  4. Redeploy (Deployments, the latest one, Redeploy), then come back here and send a test.

Gmail sends up to about 500 emails a day and they come from the Gmail address. Guests' replies still go to the host, because each email's reply-to is set to the other person.

Option B: your own domain (for example bookings@islandstay.mv)

Use an email service such as Resend, Brevo or Postmark. Verify your domain with them, then set EMAIL_HOST, EMAIL_PORT, EMAIL_HOST_USER and EMAIL_HOST_PASSWORD from their SMTP settings, plus DEFAULT_FROM_EMAIL, for example Island Stay <bookings@islandstay.mv>. For Resend: host smtp.resend.com, port 587, user resend, password your API key.
